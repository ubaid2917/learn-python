## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3 installed on your system. You can verify your installation by running:

```bash
python --version
```

### Running Scripts

To run any script from this repository, navigate to the specific folder and execute the Python file:

```bash
# Example: Running the variables practice script
python variables/main.py
```
